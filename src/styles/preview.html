# Kalamos：蘆葦筆與莎草紙的書寫體驗
Kalamos（古希臘語 *κάλαμος*）是以「蘆葦筆寫在莎草紙上」為核心意象的 WYSIWYM Markdown 編輯器。預設畫面只有一張安靜的紙，版心最寬 `720px`、字級 `17px`、行高 `1.75`（約每行 40 個中文字），讓中英混排的長文閱讀與寫作保持穩定節奏。

## 一、行內樣式與符號隱藏（無殘留空白）
在中文緊接的句子中輸入**無空白粗體**、*斜體強調*或~~刪除線文字~~時，`.k-mark-hidden` 透過 `font-size: 0; letter-spacing: 0` 收合寬度為 0px，字與字之間緊密銜接、不留任何空白；當游標進入該節點切回 `.k-mark` 時，符號以 `@keyframes`（`opacity 0 → 1, 150ms ease-out`）柔和淡入。支援赭紅色超連結 [Typora 設計參考規格](https://typora.io) 與半透明赭紅（--k-link）選取背景。
> 「紙先於工具，符號隱去，墨色有分量。」—— 蘆葦綠（--k-accent）僅用於非文字 UI（引用左邊框、指示條、狀態圖示），次要文字（--k-text-muted）維持 WCAG AA 對比度。
### 二、清單與技術筆記（Lists & Code Blocks）
  • **Papyros（莎草紙）**：暖調紙面 #F5EFE0 搭配深墨色文字 #2B2622（對比度 13.05:1）。
  • **Melan（墨）**：深墨底色 #1C1A17 搭配溫潤羊皮紙白字 #E8E0D0（對比度 13.23:1）。
  • **中英混排字體**：英文 Source Serif 4 搭配繁體中文 Noto Serif TC，介面採用 Inter 與 Noto Sans TC。
