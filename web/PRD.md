# Kalamos Web 版產品規格書（PRD）

**目前方向：** Web 版以桌面版功能為基準，公式、圖表和本機圖片預覽都是首版需求。使用者可匯入本機 Markdown，文件由使用者自管的資料庫保存，而不是只放在瀏覽器。開發先在本機進行，沒有公開網域或發布計畫。

## 1. 使用者與主要流程

使用者是在瀏覽器撰寫中英混合筆記與技術文章的 Kalamos 使用者。主要流程是：**建立文件或從本機選取 `.md` → 在單欄即時預覽中編輯 → 存入自管資料庫 → 下次從工作區重開或下載 Markdown 副本**。匯入不會改寫本機原檔。

[桌面版 README](../README.zh-TW.md) 和[桌面版 PRD](../docs/PRD.md) 是功能對齊的基準。Web 版要對齊使用者能完成的工作，而不是複製作業系統實作。例如，桌面版的本機資料夾可對應到資料庫工作區；瀏覽器不會直接讀取任意磁碟路徑。

## 2. 功能與驗收

| ID | 需求 | 驗收方式 |
| --- | --- | --- |
| WEB-01 | 建立文件或匯入使用者選取的 UTF-8 `.md`，並寫入自管資料庫；可下載 Markdown 副本。 | 匯入一份中英混合文件後，在乾淨的瀏覽器設定檔重開並下載；確認內容一致、本機原檔未變。取消或匯入失敗時，不取代目前文件。 |
| WEB-02 | 對齊桌面版即時預覽、原始碼模式、GFM、標題大綱及中英混排。保留表格儲存格編輯、程式碼高亮、MathJax 公式、Mermaid 與桌面版支援的圖表語法。 | 用同一組 Markdown 文件比對桌面與 Web 的渲染及編輯結果；涵蓋表格修改、任務清單勾選、公式、圖表語法錯誤、模式切換與繁中輸入法。 |
| WEB-03 | 支援行內圖片，並能預覽使用者明確匯入的本機圖片。保留圖片相對路徑；缺少檔案時應指出未解析的路徑。 | 匯入含 `assets/example.png` 的 Markdown，再匯入對應圖片；確認能顯示、重開後仍可讀取。未提供的圖片不應從任意本機目錄讀取。另驗證拖放、貼上與尺寸調整的對等流程。 |
| WEB-04 | 工作區包含文件清單與階層導覽，可搜尋、切換、重新命名與刪除文件。儲存以資料庫寫入成功為準，不依賴瀏覽器的草稿保存。 | 儲存後重開可讀取正確版本；資料庫中斷時顯示「尚未儲存」，維持當前編輯內容並允許重試或下載。另驗證工作區操作不會改寫匯入來源。 |
| WEB-05 | 對齊桌面版寫作工具：字數統計、專注模式、打字機模式、主題與編輯偏好。 | 相同文件的字數一致；用鍵盤測試模式切換與其他主要操作；重新開啟後偏好保留。 |
| WEB-06 | 對齊桌面版 PDF 與多格式匯入／匯出的用途。依桌面版基準盤點原生功能差異，確認等效方案。 | 驗證 PDF 的標題書籤、公式和圖表，以及選用 Pandoc 時的多格式文件往返。原生實作不同不是默認刪減功能的理由；未解決的差異需另行確認。 |

## 3. 開發與驗收界線

- **本機開發**：使用 [`compose.yaml`](./compose.yaml) 啟動 Web、API 與自管 PostgreSQL，操作方式見[本機驗收說明](./README.md)。尚不對外開放服務，不規劃公開網域。
- **資料與隱私**：文件內容傳給自己的 Kalamos API 以儲存，不傳給第三方處理或遙測。分享給他人或開放遠端存取不在本次範圍內。
- **離線**：不需要連外網即可使用本機服務和本機資源。若瀏覽器無法連到 API 或資料庫，不能承諾儲存成功；是否需要獨立於 API 的離線模式另議。
- **驗收**：以真實資料庫和瀏覽器覆蓋匯入、編輯、儲存、重開與下載，並用桌面版測試文件比對功能。現有 Vite 頁面的[記憶體模擬](../src/ipc.ts)不算 Web 資料持久化驗收。

## 4. 尚待確認

1. 首版支援的瀏覽器。建議先以桌面 Chrome／Edge 驗收，但未決定是否同時承諾 Safari／Firefox。
2. 相對路徑圖片的匯入方式（選取附件或選取資料夾）和附件儲存方式。
3. 桌面專用整合的 Web 對應方式，包括自訂圖床指令、主題檔、檔案監聽、Pandoc 執行位置與 PDF 輸出。瀏覽器不應直接執行文件內指定的命令。

資料庫方案與目前的技術建議見 [ADR 0002](./docs/decisions/0002-self-managed-database.md)。
