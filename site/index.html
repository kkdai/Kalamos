Kalamos

Write, and it appears.

A distraction-free, live-preview Markdown editor for macOS and Windows. Named after the Ancient Greek reed pen, Kalamos turns plain GFM files into crisp paper as you type — free, offline, and without accounts.

Single-Pane Live Preview

No split panes or preview buttons. Syntax markers render the instant you close them and fade out when your cursor moves away. Press Cmd+/ for raw Source Mode anytime.

Quick Open (Cmd+P)

Fuzzy-search Markdown files across the open folder with highlighted match characters. Leave the box empty to jump back to recently opened files, or use File > Open Recent.

Quick Open & Recent Files

Press Cmd+P (Ctrl+P on Windows) to fuzzy-search Markdown files across the open folder with highlighted matches. With an empty query, browse up to 20 recently opened files across folders, press Cmd+Enter to open in a new tab, or pick from File > Open Recent.

FAQ

Frequently asked questions

Why is it called Kalamos?

Kalamos (κάλαμος, pronounced KA-la-mos) is the Ancient Greek word for the reed pen used to write on papyrus. The names inside the app continue this motif: Papyros (light paper theme), Melan (dark ink theme), Ataraxia (undisturbed focus mode), and Stichos (single-line typewriter mode).

Do I need to install Pandoc?

No — Pandoc is completely optional. Everyday editing, live preview, MathJax, Mermaid diagrams, and native PDF export with bookmarks all work out of the box with zero external dependencies.

Install Pandoc (brew install pandoc on macOS or winget install JohnMacFarlane.Pandoc on Windows) only if you want to export to DOCX, ODT, LaTeX, MediaWiki, or EPUB, or import those formats into Markdown (Pandoc 2.15+ is required for sandboxed import).

Is Kalamos free and offline?

Yes. Kalamos has no accounts, no trials, no license keys, and no telemetry. Fonts, MathJax, Mermaid, and GitHub emoji data are bundled locally so everything works offline, and your notes remain plain .md files on disk.

How do I open an unnotarized macOS build?

Release builds are not Apple-notarized yet. After dragging Kalamos.app to /Applications, right-click the app in Finder and choose Open (or allow it under System Settings → Privacy & Security). You can also clear the quarantine attribute in Terminal:

xattr -cr /Applications/Kalamos.app
What should I know about the Windows version?

Windows support (Windows 10 / 11 x64) is currently experimental and unsigned. When launching the -setup.exe or .msi installer, Windows Defender SmartScreen may show a warning — click More info → Run anyway.

Kalamos requires the Microsoft Edge WebView2 Runtime, which is pre-installed on Windows 11 and automatically installed by the installer bootstrapper on Windows 10.

Can I customize themes or configure an image uploader?

Yes. Place any .css file using :root[data-custom-theme] inside ~/Library/Application Support/io.kalamos.app/themes/ (macOS) or %APPDATA%\io.kalamos.app\themes\ (Windows) to customize colors, typography, or heading numbering. For image hosting, configure uploadCommand (such as PicGo CLI) in settings.json inside that same app data folder and press Cmd+Opt+U.
