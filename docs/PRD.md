## 1. 文件資訊與背景

## 2. 問題陳述與產品目標

寫作者要的是「專心寫內容」，但現有 Markdown 工具迫使他們在語法符號與預覽結果之間來回切換。

**核心問題**

- 雙欄預覽佔用螢幕、分散注意力，視線需在兩欄之間跳動。
- 表格、數學公式、圖表的純文字語法難寫難除錯。
- 圖片、內部連結與檔案管理散落在不同工具。
- 交付時需另外轉檔（PDF、Word、LaTeX），格式常跑掉。

**產品目標**

1. **無感編輯**：單一視窗即時渲染，隱藏非當前編輯區塊的 Markdown 符號。
2. **技術內容一等公民**：程式碼、公式、圖表、表格皆可所見即所得編輯。
3. **從草稿到交付一站完成**：內建檔案管理與多格式匯入匯出。
4. **可個人化**：以 CSS 主題完全自訂外觀。
5. **免費自用**：不收費、不需帳號或序號，開啟即可使用全部功能。

## 3. 目標使用者

唯一的使用者是自己：用 Markdown 寫技術文章與部落格、同時用繁體中文與英文寫作的開發者。

| 情境 | 關鍵需求 | 對應功能 |
| --- | --- | --- |
| 技術部落格文章 | 程式碼高亮、圖片相對路徑、YAML Front Matter | BL-02、IM-04、ED-06 |
| 技術筆記與規格文件 | 表格、待辦清單、流程圖 | BL-01、ED-04、BL-04 |
| 中英混合寫作 | CJK 粗斜體、輸入法組字不跳動 | ED-03、第 7 節 |
| 交付與分享 | 匯出 PDF / DOCX | EX-01、EX-02 |

## 4. 範疇

本版專注在「本機、單人、檔案為中心」的桌面寫作體驗。

**In scope**

- 即時預覽編輯器核心（區塊與行內語法）
- 表格、程式碼、數學公式、圖表等進階區塊
- 圖片插入、縮放、路徑管理與上傳
- 檔案樹、檔案列表、大綱、字數統計
- 專注模式、打字機模式、自動配對
- 匯入 / 匯出（PDF、DOCX、ODT、LaTeX、MediaWiki、EPUB）
- CSS 主題系統
- 偏好設定（主題、行號、自動配對、公式編號等開關）

**Out of scope**

- 收費、試用期、序號、帳號與授權驗證
- 即時多人協作與評論
- 自建雲端同步（交由 Dropbox、iCloud 等第三方）
- 行動版（iOS / Android）與網頁版
- 外掛套件 / 插件市集
- 內建 AI 寫作輔助

優先級定義：P0 = 上線必要、P1 = 主要差異化、P2 = 加分項。功能描述依據 [typora.io](https://typora.io) 與 [typoraio.cn](https://typoraio.cn)。

## 6. 關鍵使用流程

核心流程是寫一篇技術文章並發布，全程不離開編輯器，也不需要登入或啟用。

1. 開啟部落格的文章資料夾，從檔案樹選擇或新增 .md 檔（NV-01）。
2. 填寫 YAML Front Matter，用即時預覽撰寫內文（ED-01、ED-06）。
3. 拖放圖片插入，路徑依部落格根目錄寫成相對路徑（IM-02、IM-04）。
4. 插入程式碼、表格、流程圖，用大綱面板檢查結構（BL-01、BL-02、BL-04、NV-02）。
5. 存檔後交由部落格發布，或匯出 PDF / DOCX 分享（EX-01、EX-02）。

## 12. 品牌與設計語言

Kalamos 的設計語言以「蘆葦筆寫在莎草紙上」為核心：介面是一張紙，工具是一支筆，需要時才出現。

### 12.1 名稱與品牌概念

| 項目 | 內容 |
| --- | --- |
| 名稱 | Kalamos（κάλαμος），古希臘人在莎草紙上寫字用的蘆葦筆 |
| 讀音 | KA-la-mos，重音在第一音節 |
| 標語 | Write, and it appears. ／ 落筆即成文 |
| 品牌個性 | 安靜、專注、有手作感、可靠 |
| 標誌 | 斜切的蘆葦筆尖，筆尖延伸一道墨線；單色即可辨識，可縮至 16 px 應用程式圖示 |

### 12.2 設計原則

1. **紙先於工具**：預設畫面只有文字，側欄與工具列需要時才出現。
2. **符號隱去**：Markdown 符號只在游標所在的區塊顯現（對應 ED-01）。
3. **墨色有分量**：色彩克制，只用墨色、紙色與一個強調色；強調色只用於當前狀態與連結。
4. **鍵盤優先**：每個操作都有快捷鍵，滑鼠是輔助。
5. **安靜的回饋**：動效短而輕，不打斷書寫。

### 12.3 色彩

兩套內建主題：Papyros（莎草紙，淺色）與 Melan（墨，深色）。文字對比度需符合 WCAG AA（4.5:1）。

| 用途 | Papyros（淺色） | Melan（深色） |
| --- | --- | --- |
| 背景（紙面） | `#F5EFE0` | `#1C1A17` |
| 側欄 / 表面 | `#EDE4CF` | `#25221E` |
| 主要文字（墨） | `#2B2622` | `#E8E0D0` |
| 次要文字 | `#6E6355` | `#9C9384` |
| 強調色（蘆葦綠） | `#5E7A4A` | `#93AE7C` |
| 連結 / 選取（赭紅） | `#A4552F` | `#D98A63` |
| 分隔線 | `#D9CDB3` | `#3A362F` |

### 12.4 字體與排版

| 用途 | 字體 | 說明 |
| --- | --- | --- |
| 內文（中文） | Noto Serif TC（思源宋體） | 書寫感，呼應紙本 |
| 內文（英文） | Source Serif 4 | 與宋體視覺重量相近 |
| 介面 | Inter + Noto Sans TC | 側欄、選單、設定 |
| 程式碼 | JetBrains Mono | 等寬，支援連字 |

排版：內文 17 px、行高 1.75、版心最寬 720 px（約每行 40 個中文字）。以上字體均為開源授權，符合第 8 節要求。

### 12.5 圖示與動效

- **圖示**：1.5 px 線條、圓頭筆劃端點，如筆跡；不用填色圖示。
- **游標**：墨色、略粗的游標，像筆尖。
- **動效**：150–200 ms、ease-out；Markdown 符號以淡出隱去，不用位移。
- **側欄**：滑入時紙面不移動，只縮小留白。
