# 表格（BL-01 / #59）

## 插入表格

- **`Cmd+Opt+T`**：開啟「插入表格」對話框。
  - 輸入「列數（含表頭）」與「欄數」，預設 3 × 3；按 Enter 或「插入」確定，Esc 或「取消」關閉。
  - 也可以在格子 picker 上移動滑鼠預覽大小，點一下直接插入。
  - 新表格各欄靠左（`:---`，同 #7 預設表格）。插入後焦點在第一個表頭格（可直接打字）。若游標所在行有文字，表格插在下一段（中間空一行）。
- **輸入 `|a|b|` 後按 Enter**：在一般段落的行尾，整行會轉成表格（表頭 `a`、`b` ＋ 分隔列 ＋ 一列空白列），游標移到第一個空白格。
  在程式碼區塊、引言、清單、既有表格中不會轉換。

## 格內公式

- 在表頭或內容格輸入 `$...$`。未編輯的格子會顯示排版後的 LaTeX；聚焦該格或切換到原始碼模式時仍顯示 Markdown。
- `\$` 和程式碼 span 內的 `$...$` 不會被當作公式。

## 結構操作

游標或聚焦中的格子在表格內時，表格上方會出現工具列（在表格正上方保留一條空間放工具列，不會蓋住任何文字；保留/移除空間時會補償捲動，正在編輯的格子在畫面上不跳動）；在表格上按右鍵會開啟相同動作的選單。

| 動作 | 快捷鍵 | 工具列 | 右鍵選單 |
| --- | --- | --- | --- |
| 上方插入列 | `Cmd+Opt+↑` | | ✓ |
| 下方插入列 | `Cmd+Opt+↓` | +列 | ✓ |
| 左側插入欄 | `Cmd+Opt+←` | | ✓ |
| 右側插入欄 | `Cmd+Opt+→` | +欄 | ✓ |
| 刪除列 | `Cmd+Shift+Backspace` | −列 | ✓ |
| 刪除欄 | `Cmd+Opt+Backspace` | −欄 | ✓ |
| 欄靠左 / 置中 / 靠右 | `Cmd+Opt+Shift+←` / `↑` / `→` | 三個對齊鈕 | ✓ |
| 欄左移 / 右移 | | | ✓ |
| 刪除表格 | | 刪表 | ✓ |

- 快捷鍵只在表格內生效（對齊不用 L/C/R，因為 `Cmd+Opt+Shift+R` 已是「清除圖片根目錄」）；在表格外按下時維持原本行為（例如 `Cmd+Opt+↑/↓` 新增上/下游標）。
- 對齊鈕是切換式：再按一次目前的對齊方式會清除對齊（`---`）。
- 表頭列不能刪除；刪掉最後一列內容列時保留表頭；刪到只剩 0 欄時刪除整張表。
- 每個操作都是一次 undo，操作後 Markdown 欄寬自動對齊（中文字寬算 2），焦點移到目標格（例如 +列 後可直接在新列打字）。
- `Cmd+Enter` 保留給「跳出表格」（格內編輯，#59 A）。

## 實作

- `src/editor/table-ops.ts`：純函式結構操作（`ParsedTable` → 新 Markdown ＋ 要選的格子）、`insertTable`、`|a|b|` + Enter。
- `src/editor/table-toolbar.ts`：浮動工具列（ViewPlugin，掛在編輯器 scroller 內，不在表格 widget 的 DOM 裡）、右鍵選單、快捷鍵。
- `src/editor/table-insert-dialog.ts`：插入表格對話框。
